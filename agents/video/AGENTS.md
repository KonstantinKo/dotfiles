# Video projects

Use `~/projects/video/` for video work. Standalone experiments live under `labs/`; Backlot productions live under `backlot/`. Choose the workflow the user asks for. Backlot's process applies inside `backlot/` and its projects.

General video skills are linked from `~/dotfiles/agents/video/skills/`. Blender is linked from `~/dotfiles/agents/creative/skills/`. Backlot skills, commands, and agents are linked only under `~/projects/video/backlot/`.

For local Blender work in Codex or Claude, use the video project's `higgsfield-use-blender` MCP and `use-blender` skill. This background Blender process is separate from the open desktop scene; save and load `.blend` files to move work between them. Its local `bl_*` tools do not spend Higgsfield credits. Higgsfield cloud generation goes through `higgsfield-generate` and the approval rule below.

The official Higgsfield CLI skills and cloud MCP are available only in video projects. Use the appropriate named skill for specialized jobs; use `higgsfield-generate` for general model, workflow, Marketing Studio, or Virality Predictor calls. The cloud MCP can browse and operate Higgsfield features beyond those exposed by the CLI. For any paid MCP operation, obtain an exact estimate through the CLI if supported, show the inputs and balance, and wait for approval of that single operation. If no exact estimate is available, stop before submitting it.

Before each paid generation or provider call, show the exact inputs, settings, estimated cost, and current balance, then wait for the user's explicit approval for that call. Setup, tutorial, and test requests do not authorize spending. Re-estimate and ask again if the call changes.
