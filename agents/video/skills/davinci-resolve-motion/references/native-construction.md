# Native Fusion construction

## Choose the graph from the visible result

Write down the output frame, safe space, reading order, source media, colors, font, and independently moving components. Build ordinary words with Text+, graphics with simple native generators/shapes/masks, and pictures as separately replaceable sources. A node branch represents a semantic part; name it for that part. Keep Merge order, alpha, masking, and effect bounds deliberate. Test the full timeline composite after moving a component into a Group or separate Fusion composition.

For typography, verify the installed font and rendered word shape in Resolve. Keep glyph proportions stable when animating tracking or position. A **Follower** modifier sequences Text+ animation character by character with delay; for word or line timing, use separate editable text elements or explicitly selected character ranges. **Character Level Styling** styles selected glyphs. Use these where they preserve editable wording. A keyed Text+ input or a limited, clearly named source can serve a type reveal. Use a custom contour or separate graphic only when the reference actually changes the glyph shape. Keep masks, backgrounds, and cursors tied to visible text bounds when the user must change the words; test a longer phrase. See Blackmagic's [Fusion product guide](https://www.blackmagicdesign.com/products/davinciresolve/fusion) and [Visual Effects Guide](https://documents.blackmagicdesign.com/ca/UserManuals/DaVinci-Resolve-20-Fusion-Visual-Effects.pdf) for Follower and Character Level Styling.

For a repeated object, decide whether instances intentionally share artwork and whether their motion or content differs. A Fusion Group organizes nodes; a macro exposes selected controls; a Fusion composition is attached to a timeline item. None automatically grants independent media replacement or independent timing. Inspect every affected consumer before changing a shared source.

## Native script boundary

Resolve's installed `Developer/Scripting/README.md` documents Console and Scripts menu invocation and `TimelineItem` Fusion composition access. The installed `DaVinciResolveScript.pyi` declares `GetFusionCompByIndex`, `GetFusionCompByName`, `AddFusionComp`, and import/export methods, but leaves `Fusion` and `FusionComp` classes without detailed members. Do not infer a Fusion setter, input ID, animation time domain, or tool attribute from the Resolve wrapper. Use the Fusion scripting documentation and tool attributes, or a small known-good node setting from a disposable UI-created example. In live mode, probe one property in a duplicate and inspect it before scaling up. In manual mode, include read-only discovery and assertions before the generated script's mutations; request a separate probe result only when an unknown input changes the implementation. State when runtime probing was unavailable.
