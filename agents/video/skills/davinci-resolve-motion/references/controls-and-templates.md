# Controls and reusable templates

Expose only controls that make ordinary edits practical: wording, palette, replacement media, layout size, and motion amount or phase where needed. Name each control, define its units, neutral value, useful range, and whether it affects one instance or a shared source. Keep manual adjustment usable during the animation; an optional demo sequence should be separate from a clean rest state. Test controls at neutral and extremes, including a state where other animation is active.

Build a readable Fusion Group for editing inside Fusion. For an Edit page title, generator, transition, or effect, create the corresponding Fusion macro/template and select which inputs are exposed. Test the saved template on a fresh timeline item from the intended Effects Library category; inspect the resulting controls on the Edit page. Blackmagic's [Fusion 20.3 Reference Manual](https://documents.blackmagicdesign.com/UserManuals/FusionManual.pdf) describes node groups, Macro Editor exposure, and template installation. A Group by itself is an organization tool, not evidence that the Edit page shows its controls.

When replacing one item must not alter another, give those items distinct content sources or explicit instance controls. When changes should propagate, keep one shared source. A duplicated graph can still point at the same media. Test by editing one instance, inspecting the other, then restoring the intended content. A longer text string and a different image aspect ratio are useful checks for bounds, padding, fit, and masks.

Do not assume an AE expression or Essential Properties setup can be translated literally. Use Fusion's native inputs, linked/published controls, modifiers, expressions, and macro exposure as appropriate for the target version. Keep formulas small and inspect the driven value and output. Establish exact input IDs and keyframe setters from Fusion documentation, a known-good UI-authored tool, or runtime introspection; the Resolve wrapper type stub does not define Fusion tool internals. A manual script may perform this discovery and check its assumptions at execution time, without a live connection during authoring.
